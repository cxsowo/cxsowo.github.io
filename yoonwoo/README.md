# 相逢的轨迹

独立静态页面，访问路径 `/yoonwoo/`。无需安装依赖。

在仓库根目录执行 `python3 -m http.server 4173`，打开 `http://localhost:4173/yoonwoo/`。

交汇前左右两个半圆盘按“上方更早、下方更晚”排列，向下滚动时后续事件从下方进入焦点；日期位于盘内、卡片位于盘外。交汇后切换为下方的大半圆，卡片沿弧线向左转动；底部刻度可点击定位事件。

滚轮向上会反向旋转。交汇过渡保留完整爱心轮廓，当前日期统一显示在顶部。

## 内容与交汇配置

编辑 `data.js` 中的 `TIMELINE_CONFIG`：

- `cardSpacing`：卡片纵深间距，默认 0.16，调小可增加前后重叠。
- `people`：双方的显示名称。
- `crossingDate`：爱心绘制阶段显示的日期。
- `crossingAt`：开始交汇的滚动比例，默认 0.46。
- `crossingDuration`：绘制爱心占用的滚动比例，默认 0.14。
- `before` / `after`：交汇前与交汇后的事件。
- `position`：事件的前进坐标，从小到大排列；用于手动调整阅读间距，不是日期的等比例刻度。
- `person`：`a`、`b` 或 `both`。
- `art`：当前为 `mountain`、`window`、`moon`、`union` 四类抽象占位图。

当前事件来自用户提供的双方资料，尚未逐条核实。左位已收录出生、2017 年东国大学入学及 2018—2025 年演艺经历；仅提供年份的事件不补写具体日期，未提供正文的事件保留为空。2025.11 为汇合月份，未知具体日期不补写。Oak Company 签约事件按用户指定调整为 2025.10，位于汇合前的右位单人线；不把无具体日期的近况或展望放入事件时间线。封面仍为抽象占位图，待补原文链接和图片。

鼠标滚动、触控滑动或键盘翻页均推进同一条时间线；反向滚动倒放。事件按钮支持键盘操作和详情弹窗。减少动态效果偏好会关闭平滑跳转与远景模糊，滚动定位仍保留。

## 中英韩语言切换

右上角支持中文、English、한국어。首次访问默认中文，选择会保存在当前浏览器；切换时保留滚动位置。页面文案与示例事件译文位于 `locales.js`。

正式事件的 `title`、`text` 为默认中文。外层卡片只显示标题，完整正文只在详情弹窗显示；正文可省略，不强制补写。已有副标题已合并到正文开头，不再使用独立的 `subtitle` 字段。可在同一事件的 `i18n` 字段填写译文（现有批量译文在 `locales.js`）：

```js
{
  id: 'event-001', person: 'a', date: '2024.03.02', position: 15,
  title: '中文标题', text: '中文正文', art: 'window',
  i18n: {
    en: { title: 'English title', text: 'English text' },
    ko: { title: '한국어 제목', text: '한국어 본문' }
  }
}
```

缺少某语言的标题或正文时，对应字段回退到中文。日期、事件位置和图片在三种语言中共用。结尾 `to be continue` 保留为固定设计文案。

日期支持 `2019`、`2022.05`、`2026.05.21`、`2025.10～11` 和 `现在`，保留用户提供的精度。`before` 中 `a` 为左位、`b` 为右位；`after` 表示汇合后的轨道，`person` 仍保留事件归属，单人经历不会自动标为共同事件。

### 韩文语气约定

韩文正文采用自然、礼貌的 해요体，适合粉圈时间线记录：亲近、轻松，但保留资料整理的分寸。标题和按钮使用简洁的名词型／中性表达。避免随意切换半语、过度敬语、公文腔或过量卖萌；不额外增加关系推测和夸张评价。

## 详情内容块

`blocks` 按数组顺序渲染，支持穿插文本、单张图片和多图相册。省略 `blocks` 时，沿用 `text` 正文与 `images` 相册；不填正文也可仅保留照片。每组相册独立切换，弹窗只允许上下滚动。

```js
blocks: [
  { type: 'text', text: '第一段文字\n换行' },
  { type: 'image', src: './images/event/photo.png', alt: '图片说明' },
  { type: 'text', text: '下一段文字' },
  { type: 'gallery', images: ['./images/event/01.jpg', './images/event/02.jpg'] },
  { type: 'text', text: '最后一段文字' }
]
```

各语言可提供自己的 `blocks`，图片路径共用。`2026.10.25` 事件已采用混排，图片存于 `images/2026-10-25/`，第 1 张为封面。昵称《大熊奇迹饼干超人yuuki》在三语中保留原文。
